## Reproducing the headline numbers

Baseline accuracy:

```bash
python scripts/benchmark_models.py --models MT-005
```

Custom error analysis and failure mechanisms:

```bash
python scripts/evaluate_experiment.py --labels MT-005-test-analysis
```

Two-model fusion:

```bash
python scripts/ensemble_thermal.py --models MT-005 MT-006 --method wbf --min-votes 1
```

Deployment latency and the mission frame-rate requirement:

```bash
python scripts/benchmark_edge_cpu.py
python scripts/coverage_requirements.py
```
